Quick reference

(g ∘ f)(x) = g(f(x))
(f ∘ g) ∘ h = f ∘ (g ∘ h)
f ∘ I = I ∘ f = f
f⁻¹ ∘ f = I and f ∘ f⁻¹ = I
(f ∘ g)⁻¹ = g⁻¹ ∘ f⁻¹ (when the inverses exist)

What is a function?

A function f: A → B assigns exactly one output in B to each input in its domain A. Notation f(x): f is the rule, x the input.

Domain, codomain, range

A = {1,2,3}, B = {2,4,6,8}, f: 1→2, 2→4, 3→6. Click to inspect.

Types of functions

One-to-one (injective)
Distinct inputs give distinct outputs.
Many-to-one
Some two inputs share an output (not injective).
Onto (surjective)
Range = codomain.
Into
Range is a proper subset of the codomain (not onto).
Bijective
Both injective and onto.
Identity / Constant
I(x) = x; constant f(x) = c.

Injective/many-to-one and onto/into are independent questions: a many-to-one function can be onto, and a one-to-one function can be into.

Real-world example

A taxi charges ₹12 per km plus a ₹50 base fare, so f(d) = 12d + 50 and f(10) = 170: each distance gives exactly one fare. Mapping students to roll numbers is one-to-one; mapping students to birth month is many-to-one, and into whenever some month is unused.

Composition lab

(f ∘ g)(x) = f(g(x)) — the inner function g is applied first. Use * between factors of x (e.g. x*(x+1)); supported: + − * / ^ ( ) sqrt abs.

Real-world example

Price ₹1000 with a ₹100 coupon g(p) = p − 100 and 18% GST f(p) = 1.18p. Coupon first: (f ∘ g)(1000) = f(900) = 1062. GST first: (g ∘ f)(1000) = g(1180) = 1080. The order changes the price, so composition is not commutative.

When is composition defined?

g ∘ f needs range(f) ⊆ domain(g): every output of f must be a valid input of g.

Compatible: A → f → B → g → C, so g ∘ f: A → C.
Incompatible: f(x) = x − 5 and g(x) = √x on the reals. f(1) = −4 is not in the domain of g, so (g ∘ f)(1) is undefined; g ∘ f is defined only for x ≥ 5.

Real-world example

Let A be students, B departments and C heads of department. f sends a student to their department and g sends a department to its head, so g ∘ f: A → C sends each student to their department head. This works only if every department that f can output has a head (range of f ⊆ domain of g).

Domain of a composite

x is valid for f ∘ g when g(x) is defined and g(x) lies in the domain of f. Example: f = sqrt(x), g = x−2 needs x−2 ≥ 0, i.e. x ≥ 2.

Real-world example

A plot of area a m² has 2 m² reserved, and the rest is made into a square. Its side is √(a − 2), that is f(g(a)) with g(a) = a − 2 and f(x) = √x. This is real only when a ≥ 2, so the domain of the composite is a ≥ 2.

Properties lab

Associativity (grouping) is a different property from commutativity (order).

Real-world example

Associativity: converting m → cm (×100) → mm (×10) → μm (×1000) gives ×1,000,000 however you group the steps, so 1 m = 1,000,000 μm. Identity: converting INR to INR (×1) leaves any amount unchanged. Commutativity: two pure multipliers (×0.8, ×1.18) commute (both give 944 from 1000), but the coupon and GST steps above do not.

Inverse functions Advanced concept

If f is invertible then f⁻¹(f(x)) = x and f(f⁻¹(x)) = x. For composites, (f ∘ g)⁻¹ = g⁻¹ ∘ f⁻¹: undo the last step first. Enter functions together with their inverses.

Real-world example

f(C) = 9C/5 + 32 converts °C to °F, and f⁻¹(F) = 5(F − 32)/9 undoes it: f(100) = 212 and f⁻¹(212) = 100. For two steps, (f ∘ g)⁻¹ = g⁻¹ ∘ f⁻¹: if you put on socks (g) then shoes (f), you must take off shoes (f⁻¹) first, then socks (g⁻¹).

Real-world example

Plot f(x) = 1.8x + 32 as the °C → °F converter: it is a straight line through (0, 32) and (100, 212). Add g(x) = x − 10 (a 10° offset) and compare f ∘ g with g ∘ f: they are parallel lines that differ by a vertical shift.
